## Major Update: AutoMacro Pro v2.0.0 is Here!
This massive update completely overhauls the user interface for a more modern look and introduces highly anticipated Quality of Life (QoL) and anti-detection features to boost your productivity and gaming.

### UI & UX Overhaul
- **Dark Mode Glassmorphism:** A new interface theme featuring transparent glass effects, custom accent colors, and offline font support (Space Grotesk & Poppins).
- **Custom Application Icons:** The application now features high-resolution custom logo icons on the Taskbar and Title bar.
- **Bilingual Support (i18n):** Added a Preferences menu with language toggle options (English & Bahasa Indonesia).
- **Dynamic & Collapsible UI:** Action buttons that dynamically adjust to the length of your hotkey text, and collapsible panels to save screen real estate.
- **Scroll Wheel Support:** Numeric input fields can now be quickly adjusted using the mouse scroll wheel.

### Macro Sequencer & Automation
- **Macro Recorder:** Record your Mouse and Keyboard inputs in real-time directly into the sequence list with just a single hotkey press.
- **Native Inline Pre-delay:** Every action now includes a built-in Delay option (no need to add separate delay steps), making your macro sequences much cleaner.
- **Advanced List Manipulation:** 
  - **Drag & Drop** support to reorder macro steps.
  - Standard keyboard shortcut support: `Ctrl+C` (Copy), `Ctrl+X` (Cut), `Ctrl+V` (Paste), `Ctrl+D` (Duplicate), Multi-select (`Ctrl/Shift+Click`), and `Delete`.
- **Mouse Scroll Action:** Full support for adding mouse scroll (up/down) actions.
- **Smart Toggle:** The Toggle button now acts intelligently as a unified Start/Stop control.

### Autoclicker & Anti-Detection
- **Humanizer (Randomizer):** Added options to randomize click intervals (e.g., ±20ms) and coordinate position radiuses (e.g., ±3px) to bypass bot/macro detection systems.
- **Profile / Preset System:** Save and load your favorite Autoclicker configurations (Farming, Idle, etc.) locally via a dropdown menu.

### New Module: Window Manager
- A new utility tab for managing other programs or game windows.
- **Make Borderless** feature to force applications into borderless windowed mode, complete with a **Restore Window** option and customizable hotkeys.

### Security & Bug Fixes (Under the Hood)
- **DPI-Aware Failsafe:** The emergency failsafe system (moving the cursor to a screen corner) now works with absolute accuracy, even on multi-monitor setups with mixed DPI scaling (e.g., 1080p and 1440p).
- The failsafe now provides visual and audio (beep) feedback when triggered.
- Aggressive input validation to prevent crashes caused by zero or negative inputs in the engine timer.
